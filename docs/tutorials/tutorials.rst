Tutorials and Examples
======================

.. contents:: Contents
   :local:
   :backlinks: none

This project includes additional tutorials and examples in the repository to help you learn by doing.

Jupyter Tutorials
-----------------

The following Jupyter notebooks are available in the ``tutorials/`` directory of the repository:

- ``bases``: Tutorials of base classes and primitives.
- ``classregistration``: Tutorials of class registries and dispatching.
- ``collections``: Tutorials of specialized collection types.
- ``composition``: Tutorials of component-based systems.
- ``functions``: Tutorials of dynamic functions and decorators.
- ``objects``: Tutorials of object helpers and properties.
- ``operations``: Tutorials of general-purpose operations.
- ``testsuite``: Tutorials related to testing foundations.
- ``versioning``: Tutorials of version handling.
- ``wrappers``: Tutorials of object wrappers.


To run the notebooks locally, install the optional dependencies and launch Jupyter:

.. code-block:: bash

   pip install -e .[jupyter]
   jupyter notebook tutorials/

Note: The documentation site does not render the notebooks directly.
